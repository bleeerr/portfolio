# Михаил Потапов — персональное портфолио

Статический сайт: React 19, TypeScript, Vite 6, Tailwind CSS 4. Backend, ключи API и внешние шрифты не требуются. Сдержанные CSS-переходы поддерживают reduced motion; отдельная библиотека анимаций не нужна.

## Запуск

Node.js 22+ (проверено с 24.19.0):

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

`dist/` содержит готовый статический сайт, PDF и медиа. Относительный `base` поддерживает размещение в подкаталоге. Для публикации скопируйте содержимое `dist/` в document root Nginx. Пример конфигурации для корня домена:

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/portfolio;
    index index.html;
    location / { try_files $uri $uri/ =404; }
    location ~* \.(webp|jpg|css|js)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

Замените домен и путь, настройте HTTPS средствами вашего сервера. В `src/profile.json` задайте реальный URL опубликованного портфолио; в `index.html` обновите абсолютный `og:image` для этого домена. URL GitHub Pages сейчас указан как предполагаемый адрес, доступность публикации не проверена. Затем пересоздайте PDF и сборку. Публикация на внешнем сервере не выполнена.

## Данные и PDF

- `src/profile.json` — профиль, контакты, навыки; общие для сайта и PDF.
- `src/projects.json` — 13 проектов и личный вклад; общие для сайта и PDF.
- `src/main.tsx` — разделы, галерея, видео по нажатию, мобильная навигация.
- `src/style.css` — адаптивная визуальная система.
- `public/resume.pdf` — готовое резюме, три страницы A4, текст и ссылки.
- `public/resume-print.html` — отдельная печатная версия.
- `scripts/resume.py` — генерация PDF через Python Playwright и Chromium.
- `scripts/optimize_media.py` — создание WebP из оригинальных JPG через Pillow.
- `assets/projects/` — сохранённые оригиналы; `public/media/` — оптимизированные материалы.

Для пересоздания PDF нужны Python, Playwright и Chromium (`/usr/bin/chromium` в облачной среде). Для медиа нужен Pillow. Если их нет: `python3 -m pip install playwright Pillow`; установите Chromium средствами вашей ОС и при необходимости измените executable_path. Затем:

```sh
python3 scripts/optimize_media.py
npm run resume
npm run build
```

После изменения данных пересоздавайте PDF. У PDF предусмотрена проверка переполнения страниц. Готовые PDF и WebP сохранены, Python не требуется для обычной сборки и работы сайта. JPG и WebP не растягиваются, скриншоты показываются через `object-fit: contain`.

## Источники и открытые вопросы

См. `CONTENT_NOTES.md`. `Resume.txt` предоставлен пользователем и использован как основной источник. Презентация превышает лимит загрузки 32 МБ; её содержимое не прочитано. Недостающие скриншоты по ссылкам из резюме заблокированы сетевым прокси.
